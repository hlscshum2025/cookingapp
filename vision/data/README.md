# 本地数据目录

`raw/receipts`、`raw/fridge`、`raw/tabletop`、`raw/bagged` 用于个人实验图片。真实小票可能包含姓名、会员号、支付信息、时间和地点；不要提交 GitHub，也不要未经清理上传公共数据集。

以后建立标注集时使用 `dataset/images/{train,val,test}` 与 `dataset/labels/{train,val,test}`，并按拍摄场景或拍摄批次分组切分，避免同一连拍序列同时进入训练集和验证集。

## 德国小票首轮验收集

- 先用 20 张跑通流程，再扩到 100 张不同的真实小票；同一张小票的多张照片不算多个独立样本。
- 100 张可分为 `dev=60 / val=20 / test=20`；`test` 在参数和规则定稿前不参与调试。
- 尽量覆盖 6–10 家超市与平铺、倾斜、折痕、反光、暗光、超长、轻度模糊等场景。
- 每张人工核对商店、日期、总额、商品行、数量/单位和行总价；将四角检测失败、OCR 错字和规则解析错误分开记录。
- 优先关注菜谱原料常用的德国食品超市；药妆、服装等非目标小票不要为了凑数量加入。
