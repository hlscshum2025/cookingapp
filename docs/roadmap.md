## 当前产品阶段

- **第一版：基础设施版，已完成。** 登录、Supabase、RLS、来源导入、菜谱 CRUD、日志、备份、域名和发布链路均已建立。

## 当前下一步

当前不再继续“为了验证而录入更多测试视频”。接下来的优先顺序是：

1. 本地验收厨房词典第一版的词汇、布局和地区别名；
2. 本地验收菜谱 → 浮动采购车 → 采购清单 → 德超/亚超筛选 → CSV 导出的完整体验；
3. 根据真实做饭采购体验调整词典分类和购物车交互；
4. 再做 DEV → PROD 只追加菜谱工具；
5. 之后继续下厨房 / 小红书多来源适配 MVP。
