# 产品与功能规划

## 1. 目标用户与使用场景

第一目标用户是项目所有者本人：收藏的视频通常已经亲自尝试并成功，真正有价值的是之后积累的修改和经验。分享功能面向朋友或家人，但公开访问者默认只能查看，不能修改私人记录。

- 不知道今天吃什么时，按用时、现有食材和菜系筛选
- 再次做一道菜时，直接查看上次调整后的版本
- 在德国购物时查询食材的德文名称和替代品
- 把普通菜改为低油、低盐或减脂版本
- 根据个人忌口（包括无麸质）排除不合适的菜
- 将某道菜通过链接或二维码分享给别人

## 2. 信息架构

### 首页

- 搜索框、最近做过、想做清单、常用分类
- “今天吃什么”快速筛选
- 收藏夹导入状态

### 菜谱详情

- 菜名、封面、来源视频、分类与标签
- 份数、时间、难度、食材、必需/可选厨具
- 原视频做法摘要与我的当前版本
- 替代食材、饮食标签和注意事项
- 历次做菜记录

### 食材词典

- 中文名、英文名、德文名和常见别名
- 德国超市货架/包装关键词
- 可替代食材、替代比例、过敏原/无麸质注意
- 被哪些菜谱使用

| P0 | 食材、厨具、步骤 | 结构化保存 |

## 4. 分类与标签体系

不要建立互斥的单层文件夹；同一道菜可以同时属于“早餐 + 快手 + 高蛋白”。

- 餐次：早餐、午餐、晚餐、夜宵、加餐
- 菜系/风格：中餐、西餐、烘焙、炸物、汤羹、甜品
- 主要食材：牛肉、猪肉、鸡肉、鱼虾、蛋奶、豆制品、蔬菜
- 烹饪方法：炒、煎、炸、烤、蒸、煮、炖、凉拌
- 时间：15 分钟内、30 分钟内、需要腌制、适合备餐
- 难度：简单、中等、复杂
- 目标：减脂、高蛋白、低油、低盐、无麸质
- 状态：只收藏、准备尝试、已成功、需改进、常做
- 个人偏好：生理期个人偏好/忌口等可配置标签

“减脂”“生理期”等标签只用于个人记录和筛选，不做疾病诊断或治疗建议。营养和健康信息需保留来源、适用条件及人工确认状态。

## 5. 修改和版本设计

每条菜谱至少保留三层：

1. **来源层**：B 站视频及提取出的原始信息。
2. **当前个人版**：自己认可、下次会照着做的版本。
3. **历史日志**：每次实际制作时的调整、结果、评分和照片。

## 6. MVP 验收标准

- 在手机浏览器正常使用
- 导入并展示收藏夹视频，失败项有明确原因
- 创建或编辑任意菜谱
- 一道菜拥有多个标签、食材、厨具和步骤
- 查看食材的中英德名称
- 保存个人改法及多次制作记录
- 按标签、时间、食材和状态筛选
- 生成不泄露私人日志的只读分享页面
