## 公开菜谱的权限边界

第二版不再允许用户在编辑页直接把私人 `recipes` 行改成 public。正确流程为：

1. 用户保存自己的私人菜谱；
2. 在菜谱详情页点击“申请发布到公开菜谱库”；
3. 数据库从私人菜谱生成一份字段白名单快照，只包含公开需要的标题、摘要、食材、步骤、标签、时间和来源等；
4. 管理员在审核队列中通过或拒绝；
5. 通过后快照写入独立 `public_recipes`，所有用户可在“公开菜谱”中只读查看；
6. 用户之后修改私人原稿不会直接改变公开版本，需要重新提交审核；旧公开版本在新版通过前保持不变。

公开快照明确不包含私人做菜日志、版本说明、字幕/OCR 证据、导入原始 metadata、账号角色或邮箱。
