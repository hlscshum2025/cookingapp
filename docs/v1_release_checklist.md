- `cookingapp.caoxiaoysm.com`、DNS 与 HTTPS 已生效；Sites 入口已公开，不再要求 ChatGPT 账号。

## 发布前必须完成

| 优先级 | 工作 | 验收条件 |
|---:|---|---|
| P0 | 真实内容闭环 | 至少 10 条视频完成“来源版 → 个人版 → 做菜日志”，其中缺失克数和火候明确标为待核验。 |
| P0 | 手动录入实机验收 | 登录状态下从 B 站原链接打开视频，新增、保存、再次编辑；同视频多配方不误覆盖。 |
| P0 | 多用户注册验收 | 注册/登录/找回/确认邮件重发已接入 CAPTCHA；下一步配置自定义 SMTP，并用第二用户完成注册、邮箱确认和空白数据隔离实测。 |
| P0 | 数据备份与恢复演练 | 能导出完整 JSON；在空测试项目按 migration 重建并恢复一份样例数据。 |
| P0 | 手机端主流程 | 在德国网络下验证登录、标签搜索入口、录入、编辑、厨房模式、日志、退出与会话恢复。 |
| P0 | 错误处理 | 保存中、保存失败、空数据、重复导入、网络中断均有明确反馈且可重试。 |
| P1 | 分享边界 | 公开页面只返回白名单菜谱字段，不出现字幕原文、私人日志、邮箱或导入元数据。 |
| P1 | 视频来源链路 | 已实现根据 `source_videos` 的 BV 号/链接内嵌或打开 B 站原视频；视频文件不下载到 Supabase。待用一条真实视频完成实机验收。 |
| P1 | 画面克数流程 | 第二版允许边看原视频边手动录入画面克数；OCR 自动识别留到第三版。 |
| P1 | 成本数据结构验收 | 用 3 道真实菜验证重量、体积、按次数均摊和每人份结果；第一版可先不做价格历史。 |
| P1 | 域名与 HTTPS | 部署完成后绑定 `caoxiaoysm.com`，验证中国和德国的 HTTPS 访问与登录回调。 |

当前已经使用邮箱+密码登录。Supabase 安全检查仍提示“泄露密码保护未开启”，但该能力仅在 Pro 及以上套餐提供。免费套餐开放注册前应至少提高密码强度、保留邮箱确认、接入 CAPTCHA，并检查邮件发送与限流；升级套餐后再开启泄露密码保护。

## 明确放到第三版

- 自动音频转写、关键帧 OCR、视频理解和批量 AI 结构化。
- 大批量来源导入、后台队列、断点续传和失败自动重试。
- 来源版与个人版的可视化差异比较、细粒度回滚和多人共同编辑。
- 自动超市搜索、价格抓取、库存、购物清单、周菜单和营养计算。
- 微信登录、多厨房调度和协作任务分配。微信小程序先做封装评估，实际开发不阻塞第二版 Web。

## 推荐发布顺序

1. 先完成 10 条真实内容和 RLS 自动化测试。
2. 在本地与手机浏览器跑完 P0 主流程。
3. 创建仅本人可访问的部署，配置 Supabase 正式回调地址。
4. 绑定 `caoxiaoysm.com`、开启 HTTPS，并分别从中国和德国网络验证。
5. 稳定使用一周后，再决定是否开放公开只读分享。
