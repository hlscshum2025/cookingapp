# B 站收藏夹本地导出工具

在你自己的已登录浏览器中导出收藏夹元数据，用于 CookingApp 的首批数据导入。脚本不会收集、显示或上传 Cookie，也不会下载视频文件。

## 最简单的使用方法

1. 用 Chrome 或 Edge 登录 B 站。
2. 打开要导出的收藏夹，例如“吃饭”收藏夹。
3. 按 `F12`，切换到 **Console / 控制台**。
4. 如果浏览器阻止粘贴，按照控制台提示手动输入 `allow pasting`，回车。
5. 打开 [`export-favorites.js`](export-favorites.js)，复制全部内容，粘贴到控制台并回车。
6. 等待控制台显示“导出完成”。浏览器会下载一个 JSON 文件。

JSON 保留完整层级信息，可直接交给 CookingApp 继续处理。为避免 Edge 拦截多个自动下载，工具不再同时下载 CSV；需要 Excel 表格时可由 CookingApp 从 JSON 转换。

## 导出的内容

- 收藏夹 ID、名称、预期视频数和导出时间
- 视频标题、BV 号、链接、UP 主及 UID
- 时长、发布时间、收藏时间、封面和简介
- 视频类型与失效标记

不包含登录 Cookie、账号密码、弹幕、视频文件、观看记录或其他收藏夹数据。

## 常见问题

### 数量不是 197 条

先看收藏夹页面本身显示的数量。失效、已删除、私密或地区受限的视频可能无法由接口返回。脚本会去除重复条目，并在 JSON 的 `expected_count` 与 `video_count` 中分别记录页面数量和实际导出数量，便于核对。

### 出现 412、请求失败或访问频繁

先刷新 B 站页面，确认收藏夹能正常显示，然后等几分钟再运行。脚本每页之间会主动停顿，避免短时间请求过快。不要在多个页面同时运行。

### 控制台提示不要粘贴代码

这是浏览器的自我防护提示。务必只运行本仓库中你已检查过的脚本；不要运行陌生人发来的代码。

### 如何交给 CookingApp 继续处理

保留 JSON 原文件，把它作为收藏夹导入源。需要人工核对时，可以在后续步骤中转换成 Excel，并添加“是否做过”“菜谱状态”等辅助列。

## 隐私与边界

所有请求都由当前 B 站页面直接发往 B 站同源接口，导出文件由浏览器本地生成。脚本没有第三方服务器地址，也不会把数据提交到 GitHub。导出文件可能反映你的私人收藏内容，请不要提交到公开仓库。

本工具仅用于导出你有权访问的收藏夹元数据。B 站页面或接口更新后，脚本可能需要同步调整。
